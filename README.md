# Exercícios com Scanner em Java

Coleção de 50 exercícios em Java para praticar estruturas de decisão, todos com entrada de dados via `Scanner` (nenhum valor fixo no código).

Os exercícios estão organizados em 6 partes, seguindo uma progressão de dificuldade.

## 🎯 Objetivo

Fixar os conceitos fundamentais de lógica de programação em Java:
- Leitura de dados via `Scanner` (texto, números inteiros, decimais e booleanos)
- Operadores aritméticos e relacionais
- Estruturas condicionais: `if`, `if/else`, `else if`, operador ternário e `switch`
- Formatação e exibição de resultados no console
